### 🌟 Comprehensive 8-Week Journey Overview

Looking back at my 8-week internship/workshop program with the **AWS - First Cloud AI Journey (FCJ)** (from **15/06/2026** to **14/08/2026**), I can confidently say this has been one of the most defining milestones in my professional development. Moving far beyond textbook theories, this program immersed me in a hands-on, practical environment where I had to independently architect, build, and deploy the **Awsplace** project—a fully functional cloud-based application.

This journey marks a massive transition from merely "knowing about the Cloud" to actually "building in the Cloud." I learned how to architect systems for high availability, ensure robust security, and optimize operational costs. Furthermore, the high-intensity nature of the program and strict weekly deadlines profoundly improved my discipline, focus, and ability to thrive in a professional, agile work environment.

### 🛠️ In-Depth Technical Skill Stack Acquired

The FCJ program helped me build a robust and highly demanded technology stack:
- **Compute & Storage:** Confidently provisioning and managing **EC2** instances (Linux/Windows). Efficiently managing static assets with **Amazon S3** and configuring block storage with **EBS**.
- **Database Management:** Deploying and managing relational databases with **Amazon RDS** (MySQL/PostgreSQL), understanding backup retention and Multi-AZ deployments.
- **Networking & Content Delivery:** Utilizing **Route 53** for domain management (e.g., `bvaq-workshop.space`) and configuring **CloudFront** as a global CDN to accelerate content delivery.
- **Version Control & DevOps:** Proficient in using **Git** and **GitHub** for source code management, branching strategies, and secure merges.

---

### 🏆 Key Challenges Overcome

1. **Custom Domain & SSL Configuration:** Initially, I faced significant hurdles with SSL Certificate Validation and pointing DNS records (CNAME/ALIAS) from Namecheap to AWS CloudFront. By patiently researching DNS propagation and Route 53 mechanics, I completely resolved the issues, achieving a stable, HTTPS-secured application.
2. **IAM Permission Denied Errors:** There were times when the system reported access errors (e.g., an EC2 instance failing to read from S3). Instead of dangerously granting full Admin access as a quick fix, I learned to read CloudTrail logs and IAM policy simulators to grant the exact, least-privilege permissions required.

The end of this program is not the finish line; it is a launchpad. Here are my actionable goals for the next 3-6 months:

1. **Achieve Global AWS Certification:** 
   - Dedicate focused study time to pass the **AWS Certified Solutions Architect – Associate** exam to formally validate my architectural skills and cloud expertise.
2. **Level Up with Infrastructure as Code (IaC):** 
   - While the AWS Management Console is great for learning, it doesn't scale for enterprise projects. I will begin learning **Terraform** or **AWS CloudFormation** to provision and manage infrastructure entirely through code.
3. **Deep Dive into AI/ML Integration:** 
   - Riding the AI wave, I plan to explore services like **Amazon Bedrock**, **Amazon SageMaker**, and **Amazon Rekognition** to integrate intelligent features (like generative AI chatbots or image analysis) into my future applications.
